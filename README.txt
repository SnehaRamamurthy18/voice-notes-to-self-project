# Voice Notes to Self

## Overview
"Voice Note to Self" is a concept project designed to help users record, manage, and reflect on personal voice notes. The application focuses on simplicity and ease of use, allowing users to quickly capture thoughts through voice instead of typing.

## Purpose
This project was created as a self-initiated case study to demonstrate Business Analyst documentation and process skills. It showcases how to analyze user needs and translate them into clear requirements and design documents.

## Features
- Record personal voice notes
- Auto-transcription using Speech-to-Text
- Tag and organize notes by category
- Edit, delete, and play back saved recordings
- Search and filter functionality

## Documents Included
- BRD (Business Requirements Document)
- FRD (Functional Requirements Document)
- User Stories
- Use Cases
- Wireframes – Created using Axure
- Flowcharts – Created using MS Word

## Tools Referenced
- Axure (for wireframes)
- MS Word (for flowcharts and documents)
